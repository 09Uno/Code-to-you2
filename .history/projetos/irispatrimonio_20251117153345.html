IRIS — Sistema de Gestão de Patrimônio

Aplicação para cadastro, transferência e confirmação de bens patrimoniais — foco em rastreabilidade e integrações.

Cliente: Interno / Demo Função: Fullstack (ênfase Backend) Tecnologias: Angular · TypeScript · ASP.NET Core · Dapper · SQL Server · Docker · MinIO

Visão Geral

IRIS é um sistema pensado para gerenciar bens patrimoniais dentro de uma organização. Ele traz funcionalidades de cadastro, movimentação entre setores, transferências e um fluxo de confirmação por parte do responsável pelo destino.

Problema

Muitas organizações têm dificuldade em rastrear fisicamente seus bens, confirmar recebimentos e gerar relatórios confiáveis sem processos manuais e planilhas fragilizadas.

Solução

  • Registro centralizado de bens com histórico de movimentações.
  • Transferências com confirmação por QR-code e notificações.
  • Integração entre frontend Angular e API RESTful em .NET, com armazenamento de arquivos em MinIO.

Fluxos Principais (Frontend)

  • Assets list / busca / filtros.
  • Formulários para cadastro e edição de bens (validações locais e server-side).
  • Transferência: seleção de destino, geração de protocolo e QR-code.
  • Confirmação: responsável recebe link/QR e confirma recebimento.

Arquitetura e Backend (resumo)

API construída em ASP.NET Core (.NET 6+), com endpoints REST para CRUD de bens, transferências, e geração de relatórios. Persistência via SQL Server. Acesso a objetos/arquivos (ex.: fotos do bem) via MinIO. Autenticação baseada em JWT e integração com Azure AD para ambientes corporativos quando necessário.

Decisões Técnicas Relevantes

  • Uso de Dapper para queries diretas e mapeamento simples, mantendo controle fino sobre SQL e performance.
  • Arquivos grandes e fotos guardadas em MinIO para reduzir carga no banco e facilitar backups.
  • Operações idempotentes em endpoints críticos (transferências) para evitar duplicação em tentativas/retries.
  • Workers/Hosted Services para envio de alertas, lembretes e processamento assíncrono de relatórios.

Como Executar (locally)

Frontend (Angular)

# dentro da pasta frontend (exemplo)
npm install
npm run start

Backend (.NET)

# restaurar e rodar a API
dotnet restore
dotnet run --project Iris.Api/Iris.Api.csproj

Dependências externas

  • SQL Server - string de conexão em appsettings.json
  • MinIO - endpoint e credenciais configuráveis via variáveis de ambiente
