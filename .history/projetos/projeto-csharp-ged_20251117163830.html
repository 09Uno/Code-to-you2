Sobre o Projeto

Visão Geral

IRIS é um sistema para gerenciamento de bens patrimoniais: cadastro, movimentação, transferências entre unidades e confirmação por parte do responsável pelo destino. O foco foi garantir rastreabilidade, facilidade de auditoria e integração com sistemas corporativos.

O Problema

No caso do CREABA, o processo de controle de patrimônio era realizado com planilhas e procedimentos manuais, o que resultava em perdas, inconsistências e dificuldade para comprovar localização e estado dos bens.

A Solução

Desenvolvemos um frontend em Angular para operações de cadastro, consulta e fluxo de transferência, e uma API RESTful em ASP.NET Core responsável por regras, persistência e integrações (armazenamento de arquivos em MinIO). O fluxo de transferência inclui geração de protocolo e confirmação via QR-code/link para o destinatário.

Fluxos Principais (Frontend)

  • Listagem de ativos com filtros, paginação e busca por atributos.
  • Formulário de cadastro/edição com validações e upload de fotos.
  • Transferência entre setores com geração de protocolo.
  • Confirmação de recebimento pelo responsável por e-mail (mobile-friendly).

Backend — Resumo Técnico

API em ASP.NET Core (.NET 6/8 compatível), usando Dapper para queries críticas (controle fino sobre SQL) e SqlClient para operações transacionais. Persistência em SQL Server; arquivos e imagens armazenados em MinIO. Autenticação com JWT e opção de integração com Azure AD em ambientes corporativos.

Decisões Técnicas Relevantes

  • Uso de Dapper em endpoints com consultas complexas e alto volume para performance.
  • Idempotência em endpoints de transferência para evitar duplicação em retries.
  • MinIO para objetos (fotos/documentos) desacoplados do DB.
  • Hosted Services para processamento assíncrono (notificações, reminders, relatórios).

Desafios e Soluções

Desafio: Confirmação e Rastreabilidade

Garantir que a transferência seja confirmada pelo responsável no destino, mesmo quando o destinatário está off-line ou usando dispositivos móveis.

Solução Implementada

O sistema gera um protocolo; o destinatário confirma via e-mail. Para casos offline, as confirmações são reconciliadas via um worker que processa confirmações recebidas por webhook ou por importação offline.

Desafio: Armazenamento de Mídia e Backup

Fotos e documentos aumentavam o tamanho do banco e impactavam backups/restore.

Solução Implementada

Removi blobs do banco e armazenei arquivos em MinIO, mantendo referências no banco. Isso reduziu o tamanho do DB e acelerou backups/restore.

Desafio: Idempotência em Transferências

Requisições duplicadas devido a retries do cliente poderiam gerar transfers duplicadas e inconsistências no inventário.

Solução Implementada

Implementei tokens de idempotência e checagens no servidor, garantindo que operações com o mesmo token não sejam aplicadas duas vezes. Endpoints críticos verificam o estado antes de criar novas entradas.

Exemplos de Código

Trechos ilustrativos e explicações (Controller → Service → Repository)

C# - Controller (Confirmar Transferência)

Controller fino que delega a validação e a execução ao Service. Recebe a requisição, valida autorização e retorna o status HTTP apropriado.

[ApiController]
[Route("api/[controller]")]
public class TransferencyController : ControllerBase
{
    private readonly ITransferencyService _transferService;
    public TransferencyController(ITransferencyService transferService)
    {
        _transferService = transferService;
    }

    // POST api/transferency/{id}/confirm
    [HttpPost("{id}/confirm")]
    [Authorize]
    public async Task Confirm(long id)
    {
        var result = await _transferService.ConfirmTransferAsync(id);
        if (!result)
            return NotFound(new { success = false, message = "Transferência não encontrada ou já processada." });

        return Ok(new { success = true, message = "Transferência confirmada." });
    }
}
C# - Service (Lógica de Confirmação)

Service responsável por validar estado, aplicar regras de negócio, coordenar repositórios e registrar logs — garante idempotência e consistência.

public class TransferencyService : ITransferencyService
{
    private readonly ITransferencyRepository _transferRepo;
    private readonly IUnitOfWork _unitOfWork; // opcional
    private readonly ILogger _logger;

    public TransferencyService(ITransferencyRepository transferRepo, IUnitOfWork unitOfWork, ILogger logger)
    {
        _transferRepo = transferRepo;
        _unitOfWork = unitOfWork;
        _logger = logger;
    }

    public async Task ConfirmTransferAsync(long transferId)
    {
        var transfer = await _transferRepo.GetTransferByIdAsync(transferId);
        if (transfer == null || transfer.Confirmation) return false;

        transfer.Confirmation = true;
        transfer.ConfirmationDate = DateTime.UtcNow;

        await _transferRepo.UpdateTransferAsync(transfer);
        _logger.LogInformation("Transferência {TransferId} confirmada", transferId);
        return true;
    }
}
