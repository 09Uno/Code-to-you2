Microsserviço Financeiro C#/.NET
API RESTful de Alta Disponibilidade com CQRS

🚀 Visão Geral e Contexto

Desenvolvimento de um microsserviço crítico para gerenciar transações financeiras e contas de usuários. O projeto utilizou **.NET 8** e implementou o padrão **CQRS (Command Query Responsibility Segregation)** para garantir a escalabilidade e a separação de responsabilidades entre operações de leitura (Queries) e escrita (Commands).

🛠️ Stack de Tecnologias e Metodologias

  • **Linguagem/Framework:** C#, .NET 8 (ASP.NET Core Web API)
  • **Banco de Dados:** SQL Server (via Entity Framework Core)
  • **Padrões:** CQRS (utilizando MediatR), Clean Architecture.
  • **Testes:** Testes unitários com XUnit e Moq, cobertura de 90%.

💡 Desafios Técnicos e Minhas Soluções

1. Desafio: Transações Concorrentes

Lidar com um alto volume de comandos concorrentes (depósitos/saques) que poderiam levar a condições de corrida e inconsistência de dados no saldo.

Solução: Pattern Command e Bloqueio Otimista

Utilizei o padrão Command (do CQRS) e implementei **Bloqueio Otimista** (Row Versioning) no Entity Framework Core para garantir que as transações fossem atômicas e serializáveis, prevenindo a perda de dados concorrentes.

🎥 Tour Completo: Assista à Demonstração em Vídeo

Neste vídeo, demonstro a execução dos comandos e queries via Swagger UI, mostrando a baixa latência e a separação lógica das responsabilidades de leitura e escrita.

📈 Resultados Alcançados e Impacto do Projeto

  • **Escalabilidade:** Separação entre base de leitura e escrita permite processar **+500 transações/s**.
  • **Performance:** Queries de leitura 30% mais rápidas devido à otimização de DTOs e indexação.
  • **Robustez:** Cobertura de testes unitários de 90% para lógica de negócios crítica.
