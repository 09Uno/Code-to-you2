Modelo de Análise de Sentimento em Tempo Real

Acurácia: 93.5% Latência: < 100ms Stack: PyTorch, Python

Documentação Técnica e Contexto do Projeto

Este projeto foi desenvolvido como uma Prova de Conceito (PoC) para demonstrar a capacidade de aplicar técnicas de Deep Learning (LSTM) em PyTorch para classificar o sentimento de textos (reviews, comentários) com alta precisão e baixa latência. O foco era na otimização do pré-processamento de texto em Português e na estabilidade do deployment via API.

A solução envolveu a criação de um pipeline completo de ML, desde a ingestão e limpeza dos dados até a quantização e deployment final do modelo em um contêiner Docker, pronto para ser consumido por microsserviços.

Stack de Tecnologias Utilizadas

  • Linguagem Principal: Python 3.10
  • Frameworks ML: PyTorch, Pandas, Scikit-learn.
  • Deployment: API RESTful com Flask e Gunicorn.
  • Infraestrutura: Docker para conteinerização e deployment.

Desafios Técnicos e Minhas Soluções

1. Desafio: Otimização de Modelo para Latência

O modelo precisava ser leve o suficiente para classificar textos em menos de 100ms, sem comprometer a acurácia, algo difícil com modelos de Deep Learning complexos.

Solução: Quantização e Flask Assíncrono

Implementei quantização do modelo treinado (para reduzir o tamanho e acelerar o tempo de inferência). O endpoint da API foi configurado de forma assíncrona para lidar com múltiplas requisições simultâneas eficientemente.

Resultados Alcançados e Impacto do Projeto

  • Acurácia Final: 93.5% na classificação de sentimentos em Português.
  • Latência Média (API): Redução para < 100ms por requisição.
  • Pronto para Produção: Modelo empacotado e pronto para deployment via Docker.
