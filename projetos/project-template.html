Sobre o Projeto

O Problema

Empresas recebem milhares de feedbacks diariamente em redes sociais e plataformas de atendimento, mas não possuem ferramentas eficientes para analisar sentimentos em tempo real e tomar decisões rápidas.

A Solução

Desenvolvi um modelo de Machine Learning capaz de classificar textos em positivo, negativo ou neutro com 94% de acurácia. O sistema processa até 1000 mensagens por segundo e se integra facilmente via API REST.

Exemplo de Uso da API

Python 
import requests

# Endpoint da API
url = "https://api.sentimento.com/analyze"

# Dados para análise
payload = {
    "text": "Este produto é incrível! Recomendo muito!",
    "language": "pt-BR"
}

# Fazer requisição
response = requests.post(url, json=payload)
result = response.json()

print(f"Sentimento: {result['sentiment']}")
print(f"Confiança: {result['confidence']:.2%}")
# Output: Sentimento: positive
#         Confiança: 96.50%
