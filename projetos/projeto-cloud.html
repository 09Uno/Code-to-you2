Plataforma SAAS na AWS
Arquitetura Cloud com Deployment Docker/ECS

🚀 Visão Geral e Contexto

Arquitetura, *deployment* e manutenção de uma plataforma SAAS completa, utilizando serviços gerenciados da **Amazon Web Services (AWS)**. O foco do projeto foi garantir alta disponibilidade e escalabilidade automática com custo otimizado, utilizando contêineres Docker e o serviço **ECS (Elastic Container Service)**.

🛠️ Stack de Tecnologias e Metodologias

  • **Cloud:** AWS (VPC, EC2, ECS Fargate, RDS PostgreSQL).
  • **Contêineres:** Docker, ECR (Elastic Container Registry).
  • **Banco de Dados:** RDS PostgreSQL com configurações de *read replica*.
  • **CI/CD:** Pipeline automatizado via GitLab CI/CD.
Ver Diagrama de Arquitetura Código Infra (Terraform/CloudFormation)

💡 Desafios Técnicos e Minhas Soluções

1. Desafio: Resiliência e Falha de Zona

O ambiente precisava ser tolerante a falhas de zona (AZ). Uma falha em um datacenter não poderia derrubar a aplicação, que exige uptime de 99.99%.

Solução: Multi-AZ Deployment e ECS Fargate

Configurei o **VPC** e os *Load Balancers* (ALB) para balancear o tráfego em múltiplas AZs. O **ECS Fargate** foi configurado para garantir a execução de *tasks* distribuídas, re-escalando automaticamente em outra zona em caso de falha.

📈 Resultados Alcançados e Impacto do Projeto

  • **Uptime:** Alcançado o *uptime* de **99.99%** no último trimestre.
  • **Escalabilidade:** Tempo de auto-escala reduzido de 5 minutos para **90 segundos**.
  • **Otimização de Custo:** Uso de ECS Fargate reduziu o custo operacional em **35%** comparado ao EC2 tradicional.
