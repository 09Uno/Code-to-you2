Sobre o Projeto

O Problema

Sistemas financeiros empresariais precisam lidar com milhares de transações simultâneas, garantindo consistência de dados, auditoria completa e alta disponibilidade. Arquiteturas monolíticas tradicionais têm dificuldade em escalar e manter performance sob carga.

A Solução

Desenvolvi uma API RESTful robusta usando ASP.NET Core 8 com padrão CQRS (Command Query Responsibility Segregation) e Clean Architecture. O sistema separa operações de leitura e escrita, permitindo otimizações específicas para cada tipo de operação.

Implementei transações atômicas com bloqueio otimista, sistema de auditoria completo, validações de negócio com FluentValidation, e documentação automática com Swagger/OpenAPI. O sistema processa mais de 500 transações por segundo com latência média de 45ms.

Desafios Técnicos e Soluções

Desafio: Concorrência em Transações

Múltiplos usuários realizando operações simultâneas na mesma conta bancária causavam condições de corrida e inconsistências no saldo. Era necessário garantir ACID properties sem sacrificar performance.

Solução Implementada

Implementei Optimistic Concurrency Control usando RowVersion do EF Core. Cada entidade possui um campo timestamp que é verificado antes de salvar. Se houver conflito, a operação é rejeitada e o cliente deve reprocessar. Adicionalmente, usei transaction isolation level Serializable para operações críticas. Resultado: zero inconsistências em 500+ req/s.

Desafio: Performance de Queries Complexas

Relatórios financeiros com agregações, joins e filtros complexos estavam levando mais de 2 segundos para executar, causando timeout em cenários de alta carga.

Solução Implementada

Criei modelos de leitura desnormalizados (read models) específicos para queries, implementei índices compostos no SQL Server, usei AsNoTracking() para queries read-only, e adicionei Redis cache com invalidação inteligente. Para relatórios pesados, criei stored procedures otimizadas. Performance melhorou de 2s para 180ms (melhoria de 91%).

Desafio: Testabilidade com Dependências Externas

Sistema dependia de serviços externos (APIs de pagamento, email, etc), dificultando testes unitários e integração. Testes eram lentos e flakey.

Solução Implementada

Apliquei Dependency Injection com interfaces para todas as dependências externas, usei Moq para criar mocks em testes unitários, implementei InMemory database do EF Core para testes rápidos, e criei factory pattern para dados de teste. Cobertura de testes aumentou de 45% para 92%, tempo de execução da suite de testes caiu de 5min para 35s.

C# - CQRS Command 
// Command para criar transação financeira
public class CreateTransactionCommand : IRequest<TransactionResponse>
{
    public Guid AccountId { get; set; }
    public decimal Amount { get; set; }
    public TransactionType Type { get; set; }
    public string Description { get; set; }
}

// Handler com validações e regras de negócio
public class CreateTransactionHandler
    : IRequestHandler<CreateTransactionCommand, TransactionResponse>
{
    private readonly IApplicationDbContext _context;
    private readonly IValidator<CreateTransactionCommand> _validator;

    public async Task<TransactionResponse> Handle(
        CreateTransactionCommand request,
        CancellationToken cancellationToken)
    {
        // Validar comando
        await _validator.ValidateAndThrowAsync(request, cancellationToken);

        // Buscar conta com row version para controle de concorrência
        var account = await _context.Accounts
            .FirstOrDefaultAsync(a => a.Id == request.AccountId, cancellationToken);

        if (account == null)
            throw new NotFoundException(nameof(Account), request.AccountId);

        // Criar transação
        var transaction = new Transaction
        {
            AccountId = request.AccountId,
            Amount = request.Amount,
            Type = request.Type,
            Description = request.Description,
            CreatedAt = DateTime.UtcNow,
            Status = TransactionStatus.Pending
        };

        // Aplicar regras de negócio
        account.ApplyTransaction(transaction);

        _context.Transactions.Add(transaction);
        await _context.SaveChangesAsync(cancellationToken);

        return TransactionResponse.FromEntity(transaction);
    }
}
C# - CQRS Query 
// Query otimizada para leitura
public class GetAccountStatementQuery : IRequest<AccountStatementDto>
{
    public Guid AccountId { get; set; }
    public DateTime StartDate { get; set; }
    public DateTime EndDate { get; set; }
}

// Handler com otimizações de leitura
public class GetAccountStatementHandler
    : IRequestHandler<GetAccountStatementQuery, AccountStatementDto>
{
    private readonly IApplicationDbContext _context;
    private readonly IDistributedCache _cache;

    public async Task<AccountStatementDto> Handle(
        GetAccountStatementQuery request,
        CancellationToken cancellationToken)
    {
        // Tentar buscar do cache
        var cacheKey = $"statement:{request.AccountId}:{request.StartDate:yyyyMMdd}";
        var cached = await _cache.GetStringAsync(cacheKey, cancellationToken);

        if (!string.IsNullOrEmpty(cached))
            return JsonSerializer.Deserialize<AccountStatementDto>(cached);

        // Query otimizada - AsNoTracking para leitura
        var statement = await _context.Transactions
            .AsNoTracking()
            .Where(t => t.AccountId == request.AccountId
                     && t.CreatedAt >= request.StartDate
                     && t.CreatedAt <= request.EndDate)
            .OrderByDescending(t => t.CreatedAt)
            .Select(t => new TransactionDto
            {
                Id = t.Id,
                Amount = t.Amount,
                Type = t.Type,
                Description = t.Description,
                CreatedAt = t.CreatedAt
            })
            .ToListAsync(cancellationToken);

        var result = new AccountStatementDto
        {
            AccountId = request.AccountId,
            Period = $"{request.StartDate:dd/MM/yyyy} - {request.EndDate:dd/MM/yyyy}",
            Transactions = statement,
            Balance = statement.Sum(t => t.Type == TransactionType.Credit
                ? t.Amount : -t.Amount)
        };

        // Cachear resultado por 5 minutos
        await _cache.SetStringAsync(
            cacheKey,
            JsonSerializer.Serialize(result),
            new DistributedCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = TimeSpan.FromMinutes(5)
            },
            cancellationToken);

        return result;
    }
}
C# - API Controller 
[ApiController]
[Route("api/[controller]")]
[Produces("application/json")]
public class TransactionsController : ControllerBase
{
    private readonly IMediator _mediator;

    public TransactionsController(IMediator mediator)
    {
        _mediator = mediator;
    }

    /// <summary>
    /// Cria uma nova transação financeira
    /// </summary>
    /// <param name="command">Dados da transação</param>
    /// <returns>Transação criada</returns>
    [HttpPost]
    [ProducesResponseType(typeof(TransactionResponse), StatusCodes.Status201Created)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    public async Task<IActionResult> Create(
        [FromBody] CreateTransactionCommand command)
    {
        var result = await _mediator.Send(command);
        return CreatedAtAction(nameof(GetById), new { id = result.Id }, result);
    }

    /// <summary>
    /// Obtém extrato da conta
    /// </summary>
    /// <param name="query">Filtros de consulta</param>
    /// <returns>Extrato da conta</returns>
    [HttpGet("statement")]
    [ProducesResponseType(typeof(AccountStatementDto), StatusCodes.Status200OK)]
    public async Task<IActionResult> GetStatement(
        [FromQuery] GetAccountStatementQuery query)
    {
        var result = await _mediator.Send(query);
        return Ok(result);
    }
}
