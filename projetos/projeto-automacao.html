Sistema de Automação de Backoffice
Automação de Processos Complexos com Python/PowerShell

🚀 Visão Geral e Contexto

Criação de um *pipeline* de automação robusto para o setor de Backoffice, responsável pela conciliação de dados de planilhas e sistemas legados. O sistema é um *agente* programado para rodar em horários específicos, lendo arquivos CSV, validando dados e inserindo informações em um sistema de gestão via API/simulação de UI.

🛠️ Stack de Tecnologias e Metodologias

  • **Core:** Scripts de tratamento de dados e validação em Python (Pandas).
  • **Execução:** PowerShell (Agendamento, tratamento de ambiente).
  • **Entrada/Saída:** Manipulação de arquivos CSV, Excel e XML.
  • **Segurança:** Gerenciamento de credenciais via variáveis de ambiente seguras.

💡 Desafios Técnicos e Minhas Soluções

1. Desafio: Robustez em Falhas de UI

O sistema legado não possuía API, exigindo automação via simulação de interface (RPA). Qualquer mudança visual no sistema quebrava a rotina de automação, exigindo manutenção constante.

Solução: Estratégia Híbrida e Log Detalhado

Mudei para uma estratégia híbrida: Python para **validação e conciliação** (90% do trabalho) e **PowerShell** apenas para o *login* e envio final de dados (o mínimo de interação com UI). Implementei um sistema de *log* detalhado com *screenshots* em caso de erro de UI.

📈 Resultados Alcançados e Impacto do Projeto

  • **Redução de Custo:** Economia de **80 horas/mês** de trabalho manual.
  • **Velocidade:** Processamento de 10.000 registros em **2 minutos** (antes levava 4 horas).
  • **Qualidade:** Redução de erros de conciliação para **0%**.
