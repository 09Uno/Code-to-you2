Sobre o Projeto

O Problema

Empresas recebem milhares de feedbacks diariamente em redes sociais, e-commerce e plataformas de atendimento, mas não possuem ferramentas eficientes para analisar sentimentos em tempo real e tomar decisões rápidas baseadas em dados. A análise manual é lenta, cara e propensa a erros humanos.

A Solução

Desenvolvi um sistema completo de Machine Learning capaz de classificar textos em positivo, negativo ou neutro com 94% de acurácia. O modelo utiliza técnicas avançadas de NLP (Natural Language Processing) com redes neurais LSTM e transformers BERT fine-tunados para português brasileiro.

O sistema processa até 1000 mensagens por segundo e se integra facilmente via API REST, oferecendo latência inferior a 100ms. Inclui dashboard em tempo real para visualização de métricas e tendências de sentimento.

Desafios Técnicos e Soluções

Desafio: Latência e Performance

Modelos transformers são pesados e lentos. Era necessário atingir latência inferior a 100ms para uso em aplicações real-time.

Solução Implementada

Implementei quantização de modelo (INT8), distilação de conhecimento para criar versão lightweight do BERT, cache em Redis para consultas repetidas, e batch processing para otimizar GPU utilization. Resultado: latência reduzida de 350ms para 85ms (75% de melhoria).

Desafio: Português Coloquial e Gírias

Modelos pré-treinados têm dificuldade com gírias brasileiras, emojis, sarcasmo e linguagem informal de redes sociais.

Solução Implementada

Fine-tuning do BERTimbau (BERT português) com dataset customizado de 50K comentários do Twitter, Instagram e Reclame Aqui. Criei pipeline de pré-processamento específico para normalizar gírias e interpretar emojis. Acurácia aumentou de 78% para 94% em textos coloquiais.

Desafio: Escalabilidade e Custos

Necessidade de processar picos de 5000 requisições/min sem explodir custos de infraestrutura AWS.

Solução Implementada

Arquitetura serverless híbrida com auto-scaling horizontal, filas Celery para processamento assíncrono, estratégia de cache agressiva (hit rate de 65%), e modelo lightweight para requisições síncronas + modelo completo para batch. Redução de 40% nos custos de infra mantendo performance.

Exemplo de Uso da API

Integração simples e direta em Python

Python 
import requests

# Endpoint da API de Análise de Sentimento
url = "https://api.sentimento-ai.com/v1/analyze"

# Headers com autenticação
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}

# Texto para análise
payload = {
    "text": "Este produto é incrível! Recomendo muito! 😍",
    "language": "pt-BR",
    "include_confidence": True
}

# Fazer requisição POST
response = requests.post(url, json=payload, headers=headers)
result = response.json()

# Exibir resultados
print(f"Sentimento: {result['sentiment']}")
print(f"Confiança: {result['confidence']:.2%}")
print(f"Polaridade: {result['polarity']}")

# Output:
# Sentimento: positive
# Confiança: 96.50%
# Polaridade: 0.87
JavaScript 
// Exemplo de integração em Node.js
const axios = require('axios');

async function analyzeSentiment(text) {
    try {
        const response = await axios.post(
            'https://api.sentimento-ai.com/v1/analyze',
            {
                text: text,
                language: 'pt-BR',
                include_confidence: true
            },
            {
                headers: {
                    'Authorization': 'Bearer YOUR_API_KEY',
                    'Content-Type': 'application/json'
                }
            }
        );

        const { sentiment, confidence, polarity } = response.data;

        console.log(`Sentimento: ${sentiment}`);
        console.log(`Confiança: ${(confidence * 100).toFixed(2)}%`);
        console.log(`Polaridade: ${polarity}`);

        return response.data;
    } catch (error) {
        console.error('Erro na análise:', error.message);
    }
}

// Usar a função
analyzeSentiment('Adorei esse serviço! Muito bom!');
